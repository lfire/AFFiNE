# 演示文稿（幻灯片）编写规范

> 本文件仅供编写者参考，不会出现在站点中（以 `_` 开头的文件会被忽略）。
> 每章一套幻灯片：`slides/decks/NN.md`（NN 为两位章号，如 `05.md`），在线地址 `/slides/NN`。
> 播放器基于 reveal.js 5 的 Markdown 插件（marked 解析），画布尺寸 **1280 × 720**。

## 1. 分隔与结构语法

| 语法 | 含义 |
| --- | --- |
| 单独一行 `---`（前后各一个空行） | 下一张**横向**幻灯片 |
| 单独一行 `--`（前后各一个空行） | 下一张**纵向**子幻灯片（用于展开细节，慎用） |
| 单独一行以 `Note:` 开头，其后到本页结束 | **演讲者备注**（按 `S` 打开演讲者视图） |
| 行尾 `<!-- .element: class="fragment" -->` | 该元素逐步出现 |
| 页首 `<!-- .slide: class="section" -->` | 章节过渡页样式（大标题居中、主色背景） |
| ```` ```mermaid ```` 围栏 | Mermaid 图（播放器预渲染为 SVG） |
| ```` ```ts ```` 等围栏 | 代码高亮；在语言后加 `[1-3\|5]` 可分步高亮行，如 ```` ```ts [2-4|6] ```` |

**严禁**：除作为分隔符外，任何地方（包括代码块内部）出现单独成行的 `---` 或 `--`；除备注外，行首出现 `Note:`。
需要水平线时改用 `***`；YAML 示例中的 `---` 改写为注释或删去。

## 2. 版式工具类（已在播放器中定义）

```html
<div class="cols">
<div>

左栏 Markdown（注意 div 标签与内容之间必须空一行）

</div>
<div>

右栏 Markdown

</div>
</div>
```

- `<div class="cols cols-3">`：三栏。
- `<div class="callout">…</div>`：提示框（同样需要内外空行包裹 Markdown）。
- `<div class="callout warn">…</div>`：警示框。
- `<span class="tag">P0</span>`：小标签。
- `<p class="small">…</p>` / `<div class="small">`：小号文字（用于路径、脚注）。

## 3. 单页容量上限（务必遵守，否则溢出画布）

- 标题：一级 `#` 仅用于封面；内容页用 `##`，标题 ≤ 18 个汉字。
- 纯要点页：≤ 7 条，每条 ≤ 30 个汉字。
- 代码页：单个代码块 ≤ 14 行、每行 ≤ 80 字符；代码页额外文字 ≤ 3 行。
- 图表页：Mermaid 节点 ≤ 12 个，优先 `flowchart LR`/`TB`、`sequenceDiagram`（参与者 ≤ 6、消息 ≤ 12）；图下文字 ≤ 2 行。
- 表格：≤ 6 行 × 4 列，单元格文字简短。
- 两栏页：每栏遵守上述各自上限的约 60%。

## 4. Mermaid 语法安全规则

- 节点文本含 `@ / : ( ) [ ] { } " ' #` 等特殊字符时，必须写成 `A["@affine/native 绑定"]` 的引号形式。
- 不要用 `end`、`graph`、`subgraph`、`NOTE`/`Note`、`style`、`class` 作为节点或参与者 ID。
- 时序图参与者 ID 用简短英文字母（如 `UI`、`SW`、`GW`），用 `participant UI as 编辑器` 起别名。
- 不使用 `mindmap`（在幻灯片中可读性差），改用 `flowchart`。
- 编写后用 `node learning-guide/scripts/check-mermaid.mjs learning-guide/slides/decks/NN.md` 校验。

## 5. 每章幻灯片的标准结构（15–25 张）

1. **封面**：`# 第 N 章 标题`（全文件唯一的一级标题，播放器以此为标题）+ 一行副标题 + 一行“第 X 部分 · 名称 ｜ 难度 ★★★☆☆ ｜ 建议学时 N 小时”。
2. **为什么学 / 本章导读**：1 页。
3. **学习目标**：1 页，≤ 6 条。
4. **知识地图**：1 页，简化的 Mermaid 图（≤ 12 节点）。
5. **核心知识点**：10–16 页。每个知识点 1–3 页，按“概念 → 源码位置 → 关键代码/图 → 要点”组织；关键时序/架构图至少 2 张。
6. **源码导读 Top 5**：1 页表格（优先级 / 路径 / 看什么）。
7. **动手实践**：1 页，列出练习名称与验收标准要点。
8. **自测**：1–2 页，3–4 道题，答案用 fragment 逐步显示。
9. **常见坑**：1 页。
10. **小结与下一步**：1 页，3–5 条要点 + 下一章预告。

- **每张内容页都要写 `Note:` 演讲者备注**（2–5 句话，口语化讲解该页要点，可补充正文未放下的细节）。
- 内容必须忠实于对应章节文档（`learning-guide/<部分目录>/NN-*.md`），代码、路径、类名、事件名均从章节文档或源码中原样摘取，不得编造；是对章节的提炼与可视化，而非复制粘贴大段文字。
- 全部使用简体中文；路径、标识符保持英文，并用行内代码包裹。
- 不需要写“返回文档”之类的链接，播放器会自动提供。
