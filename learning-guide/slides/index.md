# 配套演示总览

每一章都配有一套在线幻灯片（每套约 25 张），提炼章节的核心概念、架构图、关键源码和自测题，适合以下场景：

- **预习**：读文档前先过一遍演示，快速建立知识框架；
- **复习**：读完文档后用演示回顾要点，检验是否掌握；
- **分享**：在团队内做技术分享时直接使用，每页都附有演讲者备注。
