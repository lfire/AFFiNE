# 配套演示总览

每一章都配有一套**交互式学习演示**（每套 20 余个场景），把章节内容重新组织为图文并茂、可自测的学习模块——成段讲解 + 架构/时序图 + 标注代码 + 对比 + 自测，而不是把要点拆成一页页 bullet。适合以下场景：

- **预习**：读文档前先过一遍演示，快速建立知识框架；
- **复习**：读完文档后用演示回顾要点，用自测检验是否掌握；
- **分享**：在团队内做技术分享时直接投屏使用。
